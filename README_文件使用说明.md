# 文件使用说明

建议阅读顺序：

1. `00_学习地图_考试信息与复习路线.md`
2. `01_Module1_NLP入门与文本预处理.md`
3. `02_Module2_语言模型与n-gram_RNN_LSTM.md`
4. `03_Module3_词表示_Word2Vec_GloVe_ELMo.md`
5. `04_Module4_Transformer_BERT_GPT.md`
6. `05_Module5_NLU_NLG任务_分类_QA_MT_对话_BLEU.md`
7. `06_Module6_LLM_Prompt_Alignment_Agent_RAG_PEFT.md`
8. `07_作业与期末题型_答题模板.md`

使用方法：

- 第一遍：按顺序读，不做题，只建立框架。
- 第二遍：每读完一个 module，闭卷写出“定义、为什么需要、怎么做、优缺点、例子”。
- 第三遍：直接做 HW1、HW2、期末参考题，把不会的题回到对应 module。

这些文档是根据项目中的 lecture、tutorial、homework、solution 和期末参考题整理的复习版，不替代原始课件；原始课件中的图和题目仍建议考试前再快速扫一遍。
